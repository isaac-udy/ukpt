# Storage records (`services.storage`)

* **Definition**: The hand-written persistence record shapes — the `XxxRow`/`XxxRecord`/`XxxInsert` `data class`es that live in a feature's `services.storage`. The *generated* `XxxRow` classes live in `platform.server.postgres.tables` instead — see [generated `Table`/`Row` sources](#generated-tablerow-sources).
