# Enro 3.0.0

The `embedded-enro` submodule is pinned to the Enro 3.0.0 release. Enro 3.0.0 changes which
APIs require an opt-in and removes one deprecated overload. The full list is in
`embedded-enro/CHANGELOG.md` under "3.0.0".

## Detection

After the submodule update, list the project's uses of the affected APIs:

```bash
grep -rnE "ExperimentalEnroApi|PathRepository|EnroController\(|NavigationContainer\(|RootContext\(|ContainerContext\(|DestinationContext\(|NavigationContainerState\(|NavigationSavedStateHolder\(" \
  --include="*.kt" app feature platform
```

## Migration

1. Remove `@OptIn(ExperimentalEnroApi::class)` and the `ExperimentalEnroApi` import where the
   opt-in covers only these APIs, which are stable in Enro 3.0.0:
   - `InstallWebHistoryPlugin` and `rememberInitialBackstackFromUrl`
   - `@NavigationPath`, `NavigationKey.PathBinding`, `getNavigationKeyFromPath`,
     `getPathFromNavigationKey` and `getBackstackFromPath`
   - `NavigationFlow`, `registerForFlowResult` and `managedFlowDestination`

   Keep the opt-in on code that uses `EmbeddedDestination`.
2. Add `@OptIn(AdvancedEnroApi::class)` to code that constructs `EnroController`,
   `NavigationContainer`, `RootContext`, `ContainerContext`, `DestinationContext`,
   `NavigationContainerState` or `NavigationSavedStateHolder` directly.
3. Replace a `rememberNavigationContainer` call that passes a `List<NavigationKey.Instance<*>>`
   with a call that passes a `NavigationBackstack`, for example `backstackOf(...)`.
4. Replace uses of `PathRepository`, which is no longer public, with `getNavigationKeyFromPath`,
   `getPathFromNavigationKey` or `getBackstackFromPath`.

## Verification

Compile every client target (`ukpt-verify`). An unused opt-in from step 1 produces a compiler
warning, not an error.
