# Rule renames, retirements, and reconciliations in the side-first catalog

Renames and removals that landed alongside the side-first catalog (`2026-07-31`). Each old id may
appear in downstream `@ArchitectureException` annotations, `// architecture-exception:` build-file
comments, and skill or documentation prose — an exemption citing a stale id silently stops
exempting.

## Detection

The project is affected if any source, build file, skill, or documentation cites one of the old ids
below — `grep` for the left-hand column (the Verification section has a ready-made pattern for the
most likely survivors).

## Renames

## Retirements

The `Coordinator`, `Operation`, and `Query` constructs, and the five `Internal*` constructs
(`InternalCoordinator`/`InternalHelper`, `InternalDataCarrier`, `InternalException`,
`InternalInterface`, `InternalObjectHelper`), are deleted outright. A construct with no rules is a
place, not a discipline; the declarations they classified are ordinary domain constructs in the
side-first layers.

## Migration

Replace each citation of an old id with its successor — in `@ArchitectureException` `ruleIds`, in
`// architecture-exception:` build-file comments, and in prose. A citation of a retired construct
has no successor: remove the exemption and reclassify the declaration under the side-first
constructs (usually it is an ordinary domain model, interface, or helper).

## Reconciliations that change enforcement

The twin copies of some rules had drifted; the shared base classes reconcile them, stricter side
winning. Two changes can flag previously-passing code — treat findings as real worklist, not noise:

- **One definition of "is a domain interface"** (full classification — `fun interface`, operator
  `invoke`, suspend-or-Flow functions, `FlowOf` naming — plus side-scoped residence) now backs
  `Repository` and data-layer injection rules on both sides.
- **`Repository.exposesDomainInterfacesAsProperties` has no not-providing exemption**: a Repository
  whose file imports no domain interfaces now fails rather than being skipped — a Repository that
  provides nothing is misclassified or unfinished.

## Verification

over the project finds nothing; `verifyArchitecture` and `validateTemplate` are green.
