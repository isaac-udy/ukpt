# Android host tests run on JUnit 5 and count by category

`testAndroidHostTest` runs on JUnit 5 with two engines: Jupiter runs the kotlin.test classes and
Vintage runs Paparazzi's JUnit 4 classes. A module with no JVM target builds its category tasks
(`unitTest`, `adapterTest`, …) from `testAndroidHostTest`, restricted to Jupiter. A module with a
JVM target runs its category tasks on the JVM only.

- `ukpt.test-categories` declares `junit-jupiter-engine` and `junit-vintage-engine` on
  `androidHostTestRuntimeOnly`. kotlin.test resolves to `kotlin-test-junit5` on the Android host.
- `ukpt.AndroidCategoryTest` is the Android host task type that Kover instruments. The Android
  category tasks and `subcutaneousAndroidHostTest` use the type.
- In the coverage build, `testAndroidHostTest` in a Paparazzi module runs only the Vintage engine
  and counts as Snapshot. `subcutaneousAndroidHostTest` counts as Subcutaneous. The report lists
  each instrumented task that ran tests but wrote no coverage data.
- The Subcutaneous harness waits for each cancelled ViewModel scope to finish before it resets
  `Dispatchers.Main`.
- New rule `ProjectRules.platformFileNamesDistinctFromCommon`: a file in a platform source set
  must not share its module, package and file name with a file in `commonMain`.
- `Testing.ClientInspection.readsOnly` and `Testing.ServerInspection.readsOnly` treat only a
  `fun interface` in a domain package as a domain interface. A sealed domain model no longer fails
  the rules.

## Detection

```bash
git grep -lnE "kotlin-test-junit([^5]|$)|kotlin\.testJunit\)" -- '*.gradle.kts' ':!embedded-*'
git grep -ln -e "import org.junit.Test" -e "import org.junit.Assert" -- '*/src/androidHostTest/*.kt' ':!embedded-*'
./gradlew verifyArchitecture
```

A project is affected if a command prints a file, or if `verifyArchitecture` reports
`ProjectRules.platformFileNamesDistinctFromCommon`.

## Migration

1. Confirm that the catalog merge added these entries to `gradle/libs.versions.toml` under `[libraries]`:
   ```toml
   junit-jupiterEngine = { module = "org.junit.jupiter:junit-jupiter-engine" }
   junit-vintageEngine = { module = "org.junit.vintage:junit-vintage-engine" }
   ```
2. In each module's `androidHostTest` dependencies, replace `kotlin-test-junit` with
   `libs.kotlin.test`.
3. Move each JUnit 4 test in `androidHostTest` that is not a Paparazzi test to kotlin.test
   (`kotlin.test.Test` and `kotlin.test` assertions). A category task runs only Jupiter tests, and
   the coverage build counts every Vintage test as Snapshot.
4. Rename each platform file that `verifyArchitecture` reports to `[Name].<platform>.kt`.
5. Delete any local copies of these build-logic fixes: the file sync replaces `build-logic`. If the
   project extended `platform/common/subcutaneous`, apply the teardown change in `withClient` by
   hand: collect each `viewModelScope` job, call `viewModels.clear()`, then call `joinAll()` on the jobs.

