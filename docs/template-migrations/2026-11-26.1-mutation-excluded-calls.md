# The mutation catalog starts with excluded calls

The root `mutation { }` block now declares `excludeCalls()` patterns for calls whose removal
changes no behaviour a test can check: console output, Koin and urpc bindings, SLF4J loggers and Ktor client
timeouts. Without them, `runMutants` reports each removed log line or timeout as a survived
mutant. The `ukpt-test-audit` skill's "Excluded calls" section lists what to add and what not to
exclude.

## Detection

```bash
grep -n 'excludeCalls' build.gradle.kts
```

A project that applies `id("ukpt.mutation")` is affected if the command prints nothing.

## Migration

1. In the root `build.gradle.kts`, add at the start of the `mutation { }` block:
   ```kotlin
   excludeCalls(
       "kotlin.io.println",
       "kotlin.io.print",
       "kotlin.Throwable.printStackTrace",
       "org.koin.*",
       "dev.isaacudy.udytils.urpc.koin.*",
       "org.slf4j.Logger.*",
       "io.ktor.client.plugins.HttpTimeoutConfig.*",
       "io.ktor.client.plugins.timeout",
   )
   ```
2. Add the project's own logging facade (for example `platform.log.Logger.*`) and its metrics or
   tracing clients to the same call. Confirm each pattern against the `callee` values of
   `remove-call` entries in `build/mutation/sites.json`.
3. Remove `ignore()` entries that the new patterns cover.

## Verification

```bash
./gradlew runMutants --max-workers=2
```

The summary's "not run" line counts the mutants that `excludeCalls` left out.
