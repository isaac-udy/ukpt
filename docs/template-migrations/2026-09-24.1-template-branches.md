# Template branches in the marker

The template can now be followed from a branch other than `main`: a flavour of the template, such
as a server-rendered variant without the Compose clients. Three things changed to support that.

- `.ukpt/template.json` records `templateBranch`, the template branch the project follows. A
  marker without it follows `main`.
- A downstream marker's `submodules` has one SHA per `path` in `.gitmodules`, rather than a fixed
  `embedded-enro` and `embedded-udytils` pair. `validateTemplate` reports a missing or extra entry.
- `ukpt-template-update` selects migrations by the commits between `templateCommit` and the
  template's current commit, not by the dates in their file names.

A template branch may also carry `.ukpt/flavour.json`, which `validateTemplate` checks when present.
Projects do not carry one.

## Detection

```bash
grep -q '"templateBranch"' .ukpt/template.json || echo "marker has no templateBranch"
```

## Migration

1. Add `"templateBranch": "main"` to `.ukpt/template.json`, unless the project was created from
   another template branch; then record that branch.
2. Make the marker's `submodules` keys match the `path` entries in `.gitmodules`: add a SHA for any
   submodule the project added, and remove the entry for any it removed.

## Verification

```bash
./gradlew validateTemplate
```
