# Test categories

Every test class now carries one category annotation from `:platform:common:testing`
(`@UnitTest`, `@SubcutaneousTest`, `@ComponentTest`, `@SnapshotTest`, `@WiringTest`,
`@AdapterTest`, `@CheckTest`, `@EndToEndTest`). A new `Testing` RuleGroup governs test sources,
which the architecture rules previously excluded. Tests run on JUnit 5, and each category has a
Gradle task (`./gradlew unitTest`, `./gradlew snapshotTest`).

The module, the conventions (`ukpt.test-categories`, applied by `ukpt.jvm-base`), the catalog
entries and the rules arrive with the file sync. Project tests need the annotation, and some need
converting.

New rules: `Testing.oneCategoryPerTestClass`, `Testing.testFunctionsAssert`, a `placement` rule per
category, `Testing.UnitTest.noInfrastructure`, `Testing.UnitTest.oneProductionClass`,
`Testing.ComponentTest.rendersMarkupOnly`, `Testing.SnapshotTest.usesTheSnapshotHarness`,
`Testing.WiringTest.resolvesTheGraph`, `ModuleRules.testSupportOnlyFromTests`, and
`architecture.everyTestDeclarationBelongsToATestConstruct`. No rule ID is renamed or removed.

## Detection

```bash
# Test classes, to annotate
grep -rl '@Test\b' --include='*.kt' app feature platform | grep '/src/test/' | grep -v '/build/'

# JUnit 4
grep -rnE 'import org\.junit\.(Test|Before|After|BeforeClass|AfterClass|Assert)' --include='*.kt' app feature platform | grep -v '/build/'
grep -rn 'kotlin.testJunit\b' --include='*.kts' app feature platform
```

## Migration

1. Add `testImplementation(projects.platform.common.testing)` to every module with tests, and
   replace `libs.kotlin.testJunit` with `libs.kotlin.test`.
2. Annotate each test class with its category. The `ukpt-testing` skill's table decides; the
   template's own tests are annotated as examples. A test that renders a page, component or event
   stream with fixed state and reads it with jsoup is `@ComponentTest`; one that compares with
   `HtmlSnapshots` is `@SnapshotTest`; one that starts the application with `testApplication`
   becomes a Subcutaneous Test in the next migration, and is `@AdapterTest` until then.
3. Convert JUnit 4 tests: `org.junit.Test` → `kotlin.test.Test`, `org.junit.Assert.*` →
   `kotlin.test.assert*` (the message moves to the last argument), `@BeforeClass`/`@AfterClass` →
   `org.junit.jupiter.api.BeforeAll`/`AfterAll` (keep `@JvmStatic`).
4. Run `verifyArchitecture` and fix each `Testing.*` failure as the `ukpt-testing` skill describes.
   A helper class in test sources that is not a test becomes a `Fake[Name]`, a top-level function,
   or a member of the test class.

## Verification

```bash
./gradlew :platform:common:architecture:verifyArchitecture
./gradlew unitTest componentTest snapshotTest wiringTest checkTest adapterTest
```

Each category task's report lists the classes annotated with that category, and the module's
`test` report lists the same total as before the migration.
