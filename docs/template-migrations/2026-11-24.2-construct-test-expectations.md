# Every architecture Construct declares the tests expected to cover it

Each Construct in the architecture catalog declares `testedBy`: the test categories expected to
cover its declarations, or no tests with a reason. A coverage report reads the expectations to
count only the expected categories.

- udytils bump: `Construct(testedBy = …)`, `TestCategory`, `TestExpectation`, and the
  `classifyArchitecture` task, which writes `build/reports/architecture/classification.json`.
- `architecture.definitions.TestCategories` declares the eight categories of
  `:platform:common:testing`; each id is the category's JUnit tag.
- `UkptArchitecture` sets `requireTestExpectations = true`: the generated integrity test
  `everyConstructDeclaresATestExpectation` fails for a Construct without `testedBy`.
- Each Construct's documentation page has a "Tested by" block.

## Detection

```bash
grep -rLE "testedBy =" $(grep -rlE ": Construct<\w+>\(" platform/common/architecture/src/main/kotlin)
```

A project is affected if the command lists a file: a Construct the project added to the catalog.

## Migration

1. Add `testedBy` to each listed Construct, using the template's Constructs as the reference:
   `testedBy = TestExpectation.anyOf(TestCategories.Subcutaneous, TestCategories.Unit)`, or
   `testedBy = TestExpectation.none("test infrastructure")`.
2. Regenerate the architecture documentation:
   `./gradlew :platform:common:architecture:updateArchitectureDocumentation`.

## Verification

```bash
./gradlew :platform:common:architecture:verifyArchitecture
./gradlew :platform:common:architecture:classifyArchitecture
```
