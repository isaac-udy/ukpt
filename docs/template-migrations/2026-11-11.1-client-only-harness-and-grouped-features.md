# Grouped features

The rule catalog supports grouped features. A feature may nest under a group directory
(`:feature:capture:insta`): the feature's name spans the group, the feature's packages nest with
the group (`feature.capture.insta.server.domain`), and the feature's `:tests` module is test
source.

`Scenario`, `Edges` and `Teardown` keep their internal constructors: this branch has one harness
module, `:platform:common:subcutaneous`.

No rule ID is added, renamed or removed.

## Detection

```bash
# Catalog files a project customised for grouped features
grep -rln 'featureNameOfPackage' platform/common/architecture/src/main/kotlin
```

## Migration

1. Apply the catalog changes through the rule sync. A project that already added grouped-feature
   support to its catalog takes the template's version of those files; the two are the same change.

## Verification

```bash
./gradlew :platform:common:architecture:verifyArchitecture
```
