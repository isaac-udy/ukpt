# Client network module and urpc host

`:feature:core` is now full-stack. `GreetingService` (`@Urpc("greeting")`) persists greetings in a
Postgres `greetings` table and streams the history to the client, which reads and writes through
the service instead of an in-memory repository. Two modules arrive with it:

- `:platform:server:host` — `Application.installServerHost(modules)` installs Koin as
  `KoinIsolated`, `WebSockets`, `routing { urpcWithKoin() }` and the `GET /` route, and closes the
  `PgNotificationBus` when the application stops.
- `:platform:client:network` — `ServerEndpointConfig(baseUrl)`, `platformHttpClientEngine()` (CIO
  on JVM, Android and iOS; the Js engine on web) and `networkDependencies`, which binds the
  `HttpClient` and the `UrpcClientFactory`.

Each client shell binds the engine and its `ServerEndpointConfig`. Both web clients proxy
`/services` and `/urpc` to `localhost:8080` from the webpack dev server. Android declares
`INTERNET` and allows cleartext to `10.0.2.2` in debug builds; the iOS `Info.plist` sets
`NSAllowsLocalNetworking`.

`ProjectRules.constructorReferenceBindings` no longer reports a binding lambda that constructs a
class from outside the project (`single { HttpClient(get()) { … } }`). No rule ID is added, renamed
or removed.

The modules, the `:feature:core` slice, the migrations, the webpack files and the skills arrive with
the file sync. A project that has its own server host, client HTTP setup or `V1__` migration merges
by hand.

## Detection

```bash
# A host that installs Koin itself instead of calling installServerHost
grep -rn 'install(Koin)\|install(KoinIsolated)' --include='*.kt' app

# Client shells that do not install networkDependencies
grep -rLn 'networkDependencies' app/client/common/src/commonMain/kotlin/*/*/*/ClientDependencies.kt \
  app/client/web-html/src/jsMain/kotlin/*/*/*/ClientDependencies.kt

# Engine dependencies outside :platform:client:network
grep -rn 'ktor.clientCio\|ktor.clientJs' --include='*.kts' app feature

# Migration version clash with the template's V1__greetings.sql
ls platform/server/postgres/src/main/resources/db/migration/
```

## Migration

1. Add `include(":platform:server:host")` and `include(":platform:client:network")` to
   `settings.gradle.kts`.
2. Server: depend on `projects.platform.server.host` from `:app:server`, replace the
   `install(Koin) { … }`, `install(WebSockets)` and `routing { … }` block in `Server.kt` with
   `installServerHost(serverDependencies(postgresConfig))`, and add each feature's
   `[name]ServerDependencies` to `ServerDependencies.kt`. Move any other routes into the host or
   install them after it.
3. `ServerDependenciesTest`: call `verify(extraTypes = listOf(Function0::class))`; a generated urpc
   binding takes its service as `() -> Service`.
4. Client: depend on `projects.platform.client.network` from `:app:client:common` and
   `:app:client:web-html`, and put a module binding `HttpClientEngine` (`platformHttpClientEngine()`,
   closed `onClose`) and `ServerEndpointConfig` first in both `clientDependencies` lists, followed by
   `networkDependencies`. Copy the per-platform `serverEndpointConfig()` actuals from
   `app/client/common/src/*Main/`. Remove `ktor-client-cio` and `ktor-server-*` from feature client
   modules.
5. A feature client binds its service contract with
   `single<[Name]Service> { get<UrpcClientFactory>().create() }` and injects it into its Repository.
6. Copy `webpack.config.d/dev-server-proxy.js` into `app/client/web` and `app/client/web-html`, the
   Android `INTERNET` permission and `src/debug/` network security config, and the iOS
   `NSAppTransportSecurity` entry.
7. A project whose migrations already use `V1` renumbers the template's greeting migration, or
   deletes it along with the `:feature:core` greeting slice. Merge the trigger into its own
   `R__notify_triggers.sql`. Run `./gradlew :platform:server:postgres:exportPostgresSchema` and
   commit `schema.sql`.

## Verification

```bash
./gradlew :app:server:test :app:client:common:jvmTest
./gradlew :platform:common:architecture:verifyArchitecture
./gradlew :app:server:smokeTestFatJar
./gradlew :app:client:web:wasmJsBrowserDevelopmentWebpack :app:client:web-html:check
```

With `./gradlew :app:server:run` running,
`curl -X POST -H 'Content-Type: application/json' -d '{}' localhost:8080/services/greeting.greet`
returns `{"greeting":{"text":"Hello"}}`, then `"Hello again"` on the next call.
