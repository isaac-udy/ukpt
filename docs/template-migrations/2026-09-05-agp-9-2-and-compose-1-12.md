# AGP 9.2.1, compileSdk 37, and the Compose 1.12 wasmJs test check

Compose Multiplatform 1.12 maps to androidx Compose 1.12, whose AAR metadata requires AGP 9.1.0 and
compileSdk 37. AGP 9.0.0's `checkDebugAarMetadata` rejects those artifacts with no opt-out, and
`compileDebugKotlin` never reaches that task, so a project can compile and still fail to assemble.
The template now pins AGP 9.2.1 with compileSdk and targetSdk 37, in its own catalog and in both
submodules: Gradle refuses to load two AGP versions in one build, and the submodules are composite
builds.

Compose Gradle plugin 1.12.0 also registers `checkComposeUiTestConfigurationFor<Target>` on every
wasmJs target whose test compilation reaches Skiko, and wires it into `wasmJsBrowserTest`. It fails
any module without `binaries.executable()`. The constraint is real only for `runComposeUiTest`
(CMP-4906); plain `kotlin.test` suites run in the browser without a bundle. `ukpt.compose-library`
now disables the task.

## Detection

```bash
./gradlew :app:client:android:checkDebugAarMetadata
```

Fails on the base version with `requires Android Gradle plugin 9.1.0 or higher`. Independently, IDE
sync fails after the update in IntelliJ IDEA 2026.1 and earlier, whose Android plugin supports AGP
up to 9.0.0.

## Migration

1. Sync `gradle/libs.versions.toml` and `build-logic/` from the template, and repin both submodules
   (section 6 of `ukpt-template-update`). The three `agp` values must be identical.
2. Install Android SDK Platform 37 (`android-37.0` under `$ANDROID_HOME/platforms`).
3. Delete any project-added `binaries.executable()` that was put on a library module's wasmJs target
   only to satisfy the Compose check; the convention disables the check instead. Keep it on modules
   that run `runComposeUiTest` on wasmJs, and re-enable the task there.
4. Open the project in Android Studio (or an IntelliJ release whose Android plugin supports AGP
   9.2) for Android work. IntelliJ IDEA 2026.1 cannot sync the project.

## Verification

```bash
./gradlew :app:client:android:checkDebugAarMetadata :app:client:android:compileDebugKotlin
./gradlew :feature:<each>:client:wasmJsBrowserTest --no-configuration-cache
./gradlew verifyArchitecture
./gradlew validateTemplate
```
