# `testCoverageReport` replaces `subcutaneousCoverage`

`./gradlew testCoverageReport --no-configuration-cache` reports the coverage of every test category
except End-to-end. A line counts as covered only when a test from a category that the line's
Construct lists in "Tested by" runs the line. The `ukpt.test-coverage` convention plugin (in
`build-logic`) applies Kover to the root build and instruments the category tasks only when the build
runs `testCoverageReport`.

- The root `build.gradle.kts` applies `id("ukpt.test-coverage")` in place of
  `alias(libs.plugins.kover)`, and its `kover { }` block and `subcutaneousCoverage` task are removed.
- The root `testCoverage { }` block declares an expectation for each `:platform` and `:app` module:
  `testedBy(":module", "category", …)` or `noTests(":module", "reason")`. A module expectation
  applies to the lines no Construct claims.
- `gradle/libs.versions.toml` removes the `kover` plugin alias and adds the `kover-gradlePlugin` and
  `kover-featuresJvm` libraries, which `build-logic` depends on.
- `ClientUi.Screen` expects no tests: a Screen only connects a Destination and its ViewModel to the
  screen content.

## Detection

```bash
grep -n "subcutaneousCoverage\|libs.plugins.kover" build.gradle.kts
```

A project is affected if the command prints a line.

## Migration

1. In `gradle/libs.versions.toml`, delete the `kover` entry under `[plugins]` and add under
   `[libraries]`:
   ```toml
   kover-gradlePlugin = { module = "org.jetbrains.kotlinx:kover-gradle-plugin", version.ref = "kover" }
   kover-featuresJvm = { module = "org.jetbrains.kotlinx:kover-features-jvm", version.ref = "kover" }
   ```
2. In the root `build.gradle.kts`, replace `alias(libs.plugins.kover)` with
   `id("ukpt.test-coverage")`, and delete the coverage comment, the `coverageHostTask` and
   `uninstrumentedTestTasks` values, the `kover { }` block and the `subcutaneousCoverage` task.
3. Add a `testCoverage { }` block to the root `build.gradle.kts` with one line per `:platform` and
   `:app` module, using the template's block as the reference. A project-added module gets
   `testedBy` with the categories that test it, or `noTests` with a reason.
4. If the project changed `ClientUi.Screen`'s `testedBy`, keep the project's value; otherwise the
   catalog sync applies the template's. Regenerate the architecture documentation:
   `./gradlew :platform:common:architecture:updateArchitectureDocumentation`.

## Verification

```bash
./gradlew testCoverageReport --no-configuration-cache
```

The console summary lists no module under "No module expectation", and
`build/reports/test-coverage/index.html` lists no report problems.
