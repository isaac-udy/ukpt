# Subcutaneous Tests check the server and the edges through Inspections

A Subcutaneous Test can check the other end of the system besides the ViewModel state: what the
server stored, and what a fake at an edge received. Before this change a test could read the
server only through `service<S>()`, or through a Scenario, which is setup by name and by rule.

- `inspectServer { }` and `inspectClient { }` on the test scope run a block until the block
  passes or 10 s of real time pass, and return the block's result.
- New Testing constructs `ServerInspection` and `ClientInspection`: a function with a
  `ServerInspection` or `ClientInspection` receiver in a `:tests` module's `src/commonMain`. A
  function with one of these receivers is no longer a Fixture.
- `ServerInspection.server<T>()`, `ClientInspection.client<T>()`, and
  `ServerInspection.database { }` (`:platform:common:subcutaneous-server`), a read-only
  transaction on the test's database.
- `Recording<T>` (`:platform:common:subcutaneous`): a Fake records its calls; an Inspection reads
  them with `calls`, `assertSingle { … }` and `assertNone { … }`.
- New rules: `Testing.ServerInspection.placement`, `Testing.ServerInspection.readsOnly`,
  `Testing.ClientInspection.placement`, `Testing.ClientInspection.readsOnly`.
- `awaitAsserted` takes a suspending assertion. Existing calls compile unchanged.
- `ukpt.feature-tests` treats a dependency on a `:platform:server:*` module as a server
  dependency: such a `:tests` module fails configuration when its `ukpt.subcutaneousHosts`
  lists `ios`, `wasmJs` or `js`.

## Detection

```bash
grep -rn "ServerInspection\|ClientInspection" --include='*.kt' feature
grep -rn "platform.server" feature/*/tests/build.gradle.kts
```

A project is affected only if a `:tests` module already declares a function with a receiver
named `ServerInspection` or `ClientInspection`, or a `:tests` module depends on a
`:platform:server:*` module and lists a non-JVM host.

## Migration

1. Rename a project function whose receiver is named `ServerInspection` or `ClientInspection` and
   is not the harness type, or move it to the `:tests` module's `src/commonMain`.
2. Remove `ios`, `wasmJs` and `js` from the `ukpt.subcutaneousHosts` of a `:tests` module that
   depends on a `:platform:server:*` module.
3. Optional: replace a Scenario or a `service<S>()` call that a test uses only to check server
   state with a Server Inspection called inside `inspectServer { }`. The `ukpt-testing` skill,
   "Inspections", shows the shape.

## Verification

```bash
./gradlew verifyArchitecture
./gradlew subcutaneousJvmTest
```
