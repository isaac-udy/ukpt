# The web client installs Enro's web history plugin by default

`App()` creates its root container with `rememberRootNavigationContainer(root)`, an `expect`
composable in `app/client/common`. The wasm `actual` starts the container on the destination whose
`@NavigationPath` matches the address bar (`rememberInitialBackstackFromUrl`), falling back to
`root`, and calls `InstallWebHistoryPlugin`. Browser back and forward then move through the
container tree, and the address bar shows the path of the deepest active destination that has one.
The Android, desktop and iOS `actual`s create the container on `root` alone.

`UkptDestination` is bound to `/`. `ConfirmResetDestination` has no path: a cold load resolves a
path to a single-entry backstack, which would show the dialog with no screen beneath it.

## Detection

```bash
grep -rn "rememberRootNavigationContainer\|InstallWebHistoryPlugin" app/client/common/src
grep -rn "@NavigationPath" feature --include='*.kt'
```

A project that already installs `InstallWebHistoryPlugin` from its own composable is affected by
step 2.

## Migration

1. Take `RootNavigationContainer.kt` (commonMain) and its four `actual`s (`androidMain`, `jvmMain`,
   `iosMain`, `wasmJsMain`) into `app/client/common`, and replace the root
   `rememberNavigationContainer(...)` call in `App.kt` with
   `rememberRootNavigationContainer(<the project's root destination>)`.
2. A project with its own web history installation removes it, or keeps it and leaves the wasm
   `actual` creating the container without `InstallWebHistoryPlugin`. The plugin must be installed
   once per root container.
3. Add `@NavigationPath` (with `@OptIn(ExperimentalEnroApi::class)`) to the navigation keys of
   screens a visitor can link to. Dialogs and other destinations that need a screen beneath them get
   no path. Parameterised keys bind their properties by name, as in `@NavigationPath("/items/{itemId}")`.
4. The host must answer unknown paths with `index.html`; see `ukpt-web-deploy`.

## Verification

```bash
./gradlew :app:client:web:wasmJsBrowserDevelopmentRun --no-configuration-cache
```

Open a destination that has a path and confirm the address bar shows it; open a dialog and confirm
browser back closes it and browser forward reopens it. Build the production distribution, serve it
with an `index.html` fallback, and reload a bound path to confirm the app starts on that destination.
