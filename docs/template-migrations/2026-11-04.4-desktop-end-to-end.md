# Browser end-to-end tests

End To End Tests now run, in headless Chromium through Playwright. `:app:server`'s `src/test`
starts the server graph on a free local port with the harness's `inProcessServer(server, edges)`,
then opens a browser tab there with `asUserInBrowser(path) { … }` from the new
`:platform:common:browser`. The tab is driven by the same page robots the Subcutaneous Tests use,
and the test fails if the page logged an error to the console, which is where Chromium reports a
content security policy violation. `GreetingJourneyTest` is the worked example: it greets someone,
checks the Alpine character count, and removes a greeting.

The `ukpt.end-to-end-tests` convention registers `installEndToEndBrowser`, which installs the
Chromium headless shell (with its system libraries when `CI` is set), and makes `test` and
`endToEndTest` depend on it. Playwright never downloads browsers itself.

`serverDependencies` in `:app:server` is public, for the test set.

The browser module, the convention, the `playwright` catalog entry and the rules arrive with the
file sync. The `:app:server` build file and the tests are project code.

New rules: `Testing.EndToEndTest.placement`, `.drivesTheServerInABrowser`, `.drivesThroughRobots`.
Changed rules: `Testing.testFunctionsAssert` counts a robot's `see…` calls as assertions;
`ModuleRules.testSupportOnlyFromTests` lists `:platform:common:robots` and
`:platform:common:browser`. No rule ID is renamed or removed.

## Detection

```bash
# serverDependencies still internal
grep -rn 'internal fun serverDependencies' --include='*.kt' app/server

# The server test set
ls app/server/src/test/kotlin/*/*/*/
```

## Migration

1. Make `serverDependencies` in `app/server/.../ServerDependencies.kt` public.
2. In `app/server/build.gradle.kts`, apply `id("ukpt.end-to-end-tests")` and add
   `testImplementation(projects.platform.common.browser)` and a `testImplementation` of each
   feature `:tests` module the tests seed through and drive.
3. Write one `@EndToEndTest` for the project's main journey, copying `GreetingJourneyTest.kt`:
   seed with `given { }`, then `asUserInBrowser(<Name>Paths.…) { on<Name>Page { … } }`. Put the
   steps only a browser can check, such as what Alpine renders, in the robot as `see…` functions.

## Verification

```bash
./gradlew :app:server:endToEndTest
./gradlew :platform:common:architecture:verifyArchitecture
```

The first run downloads the Chromium headless shell. `endToEndTest` runs the classes annotated
`@EndToEndTest`. `verifyArchitecture` reports no `Testing.EndToEndTest.*` or `Testing.Robot.*`
failures.
