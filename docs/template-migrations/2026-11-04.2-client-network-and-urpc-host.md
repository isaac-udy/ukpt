# Server host and Postgres-backed greetings

`:feature:core` now persists greetings in a Postgres `greetings` table instead of an in-memory
repository. A new module starts the server's graph:

- `:platform:server:host` — `Application.installServerHost(modules, contentSecurityPolicy)` installs
  Koin as `KoinIsolated`, closes the `PgNotificationBus` when the application stops, and installs
  the web platform with every `WebRoutes` binding. Several hosts can run in one JVM, which the
  Subcutaneous harness relies on.

`:feature:core`'s server domain follows `main`'s names: `FlowOfGreetingHistory` returns
`Flow<List<Greeting>>`, `UpdateGreetingHistory` adds, removes and resets, and `Greeting.id` is the
row's UUID as a `String`. `GreetingStorage` reads and writes the table and observes it through the
`PgNotificationBus`; the migrations are `V1__greetings.sql` and `R__notify_triggers.sql`.

The module, the `:feature:core` slice and the migrations arrive with the file sync. A project that
has its own `V1__` migration merges by hand.

## Detection

```bash
# A host that installs Koin and the web platform itself instead of calling installServerHost
grep -rn 'install(Koin)\|install(KoinIsolated)\|installWebPlatform(' --include='*.kt' app

# Migration version clash with the template's V1__greetings.sql
ls platform/server/postgres/src/main/resources/db/migration/
```

## Migration

1. Add `include(":platform:server:host")` to `settings.gradle.kts`.
2. Depend on `projects.platform.server.host` from `:app:server` in place of
   `projects.platform.server.web`, and replace the `install(Koin) { … }` and
   `installWebPlatform(getKoin().getAll())` lines in `Server.kt` with
   `installServerHost(serverDependencies(postgresConfig))`. A project that passes a
   `ContentSecurityPolicy` passes it as `installServerHost`'s second argument.
3. A project whose migrations already use `V1` renumbers the template's greeting migration, or
   deletes it along with the `:feature:core` greeting slice. Merge the trigger into its own
   `R__notify_triggers.sql`. Run `./gradlew :platform:server:postgres:exportPostgresSchema` and
   commit `schema.sql`.

## Verification

```bash
./gradlew :app:server:test :platform:common:architecture:verifyArchitecture
./gradlew :app:server:smokeTestFatJar
```

With `./gradlew :app:server:run` running, `http://localhost:8080/` lists the greetings, and a
greeting posted there is still listed after the server restarts.
