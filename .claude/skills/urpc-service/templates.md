# urpc-service templates

Copy these and substitute the placeholders. `<Name>` = PascalCase service base (e.g. `User`);
`<name>` = the lowercase feature/package segment (`ukpt` for `:feature:core`, else your feature);
`<wire>` = the `@Urpc` wire prefix (e.g. `user`).

## §1 — Contract (`:api`)
Path: `feature/<name>/api/src/commonMain/kotlin/feature/<name>/services/<Name>Service.kt`

```kotlin
package feature.<name>.services

import dev.isaacudy.udytils.urpc.Urpc
import kotlinx.coroutines.flow.Flow
import kotlinx.serialization.Serializable

@Urpc("<wire>")
interface <Name>Service {
    suspend fun create(request: Create.Request): Create.Response
    suspend fun get(request: Get.Request): Get.Response
    fun observe(): Flow<Observe.Response>

    object Create {
        @Serializable data class Request(val name: String)
        @Serializable data class Response(val id: String)
    }
    object Get {
        @Serializable data class Request(val id: String)
        @Serializable data class Response(val name: String)
    }
    object Observe {
        @Serializable data class Response(val ids: List<String>)
    }
}
```

## §3 — Server DI module (`:server`)
Path: `feature/<name>/server/src/main/kotlin/feature/<name>/<name>ServerDependencies.kt`

```kotlin
package feature.<name>

import dev.isaacudy.udytils.urpc.koin.UrpcCall
import dev.isaacudy.udytils.urpc.koin.bindService
import feature.<name>.services.<Name>Service
import feature.<name>.services.<Name>ServiceImpl
import feature.<name>.services.<Name>ServiceUrpcBinding   // generated by urpc KSP
import org.koin.core.module.dsl.scopedOf
import org.koin.dsl.bind
import org.koin.dsl.module

val <name>ServerDependencies = module {
    scope<UrpcCall> {
        scopedOf(::<Name>ServiceImpl)
            .bind(<Name>Service::class)
            .bindService(::<Name>ServiceUrpcBinding)
        // ⚠️ NOT: scoped<UrpcService> { <Name>ServiceUrpcBinding { get() } }  -> 404 trap (see SKILL.md step 4)
    }
}
```

## §4 — Host (`:app:server`, FIRST service only)
Path: `app/server/src/main/kotlin/com/isaacudy/ukpt/Server.kt`

```kotlin
package com.isaacudy.ukpt

import dev.isaacudy.udytils.urpc.koin.urpcWithKoin
import feature.<name>.<name>ServerDependencies
import io.ktor.server.application.install
import io.ktor.server.engine.embeddedServer
import io.ktor.server.netty.Netty
import io.ktor.server.routing.routing
import io.ktor.server.websocket.WebSockets
import org.koin.ktor.plugin.Koin

fun main() {
    embeddedServer(Netty, port = 8080, host = "0.0.0.0") {
        install(Koin) { modules(<name>ServerDependencies /*, other feature dependencies… */) }
        install(WebSockets)            // required even if every call is unary
        routing { urpcWithKoin() }
    }.start(wait = true)
}
```

## §5 — `:app:server` build additions (FIRST service only)
These deps are not transitive from `:feature:*:server`.

`gradle/libs.versions.toml` (add under `[libraries]`, reuses the existing `koin` version):
```toml
koin-ktor = { module = "io.insert-koin:koin-ktor", version.ref = "koin" }
```

`app/server/build.gradle.kts` (add to `dependencies { }`):
```kotlin
implementation(libs.urpc.koin)   // urpcWithKoin() + the UrpcCall qualifier
implementation(libs.koin.ktor)   // org.koin.ktor.plugin.Koin
```

## §6 — Serializable service exception (R-PROJ-02)
Path: in the `services` package (or the feature's domain package if domain/UI must see it).

```kotlin
package feature.<name>.services

import dev.isaacudy.udytils.error.PresentableException
import kotlinx.serialization.Serializable

@Serializable
class <Name>NotFoundException(
    id: String,
) : PresentableException(
    title = "Not found",
    message = "No <name> with id $id",
    retryable = false,   // set deliberately: streaming auto-retries retryable errors; unary UI shows Retry only if true
)
```
