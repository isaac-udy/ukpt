# ukpt-urpc-service templates

Copy these and substitute the placeholders. `<Name>` = PascalCase service base (e.g. `User`);
`<name>` = the lowercase feature/package segment (`ukpt` for `:feature:core`, else your feature);
`<wire>` = the `@Urpc` wire prefix (e.g. `user`).

## §1 — Contract (`:api`)
Path: `feature/<name>/api/src/commonMain/kotlin/feature/<name>/server/services/<Name>Service.kt`

```kotlin
package feature.<name>.server.services

import dev.isaacudy.udytils.urpc.Urpc
import kotlinx.coroutines.flow.Flow
import kotlinx.serialization.Serializable

@Urpc("<wire>")
interface <Name>Service {
    suspend fun create(request: Create.Request): Create.Response
    suspend fun get(request: Get.Request): Get.Response
    fun observe(): Flow<Observe.Response>

    object Create {
        @Serializable data class Request(val name: String)
        @Serializable data class Response(val id: String)
    }
    object Get {
        @Serializable data class Request(val id: String)
        @Serializable data class Response(val name: String)
    }
    object Observe {
        @Serializable data class Response(val ids: List<String>)
    }
}
```

## §3 — Server DI module (`:server`)
Path: `feature/<name>/server/src/main/kotlin/feature/<name>/<name>ServerDependencies.kt`

```kotlin
package feature.<name>

import dev.isaacudy.udytils.urpc.koin.UrpcCall
import dev.isaacudy.udytils.urpc.koin.bindService
import feature.<name>.server.services.<Name>Service
import feature.<name>.server.services.<Name>ServiceImpl
import feature.<name>.server.services.<Name>ServiceUrpcBinding   // generated by urpc KSP
import org.koin.core.module.dsl.scopedOf
import org.koin.dsl.bind
import org.koin.dsl.module

val <name>ServerDependencies = module {
    scope<UrpcCall> {
        scopedOf(::<Name>ServiceImpl)
            .bind(<Name>Service::class)
            .bindService(::<Name>ServiceUrpcBinding)
        // ⚠️ NOT: scoped<UrpcService> { <Name>ServiceUrpcBinding { get() } }  -> 404 trap (see SKILL.md step 4)
    }
}
```

## §4 — Host registration (`:app:server`)
`Server.kt` calls `installServerHost(serverDependencies(postgresConfig))`
(`platform/server/host/.../ServerHost.kt` installs `KoinIsolated`, `WebSockets` and
`routing { urpcWithKoin() }`). A feature adds its module to the list `ServerDependenciesTest`
verifies:

```kotlin
// app/server/src/main/kotlin/com/isaacudy/ukpt/ServerDependencies.kt
import feature.<name>.<name>ServerDependencies

internal fun serverDependencies(postgresConfig: PostgresConfig): List<Module> = listOf(
    postgresDependencies(postgresConfig),
    postgresPlatformDependencies,
    ukptServerDependencies,
    <name>ServerDependencies,
)
```

`app/server/build.gradle.kts`:
```kotlin
implementation(projects.feature.<name>.server)
```

## §5 — Client binding (`:client`)
The generated `create()` extension sits in the contract's package. `UrpcClientFactory` is bound by
`:platform:client:network`'s `networkDependencies`, which both client shells install.

```kotlin
// feature/<name>/client/src/commonMain/kotlin/feature/<name>/<Name>ClientDependencies.kt
import dev.isaacudy.udytils.urpc.UrpcClientFactory
import feature.<name>.server.services.<Name>Service
import feature.<name>.server.services.create

val <name>ClientDependencies = module {
    single<<Name>Service> { get<UrpcClientFactory>().create() }
    singleOf(::<Name>Repository)
    // single<DomainInterface> { get<<Name>Repository>().domainInterface } for each property
}
```

## §6 — Serializable service exception (`ProjectRules.serviceExceptionsSerializable`)
Path: `feature/<name>/api/src/commonMain/kotlin/feature/<name>/<Name>NotFoundException.kt` — a
failure the service throws is wire-visible, so both sides name it: it is a
`FeatureRules.SharedException` in the feature root, in `:api`. (A failure only one side handles is
a side-private domain exception instead, in that side's `domain`.)

```kotlin
package feature.<name>

import dev.isaacudy.udytils.error.PresentableException
import kotlinx.serialization.Serializable

@Serializable
class <Name>NotFoundException(
    id: String,
) : PresentableException(
    title = "Not found",
    message = "No <name> with id $id",
    retryable = false,   // set deliberately: streaming auto-retries retryable errors; unary UI shows Retry only if true
)
```
